
# 🛒 Hoorify - PC Hardware E-Commerce Website

Hoorify is a responsive front-end e-commerce website for browsing and shopping computer hardware and accessories. The project is built using HTML, CSS, and JavaScript, focusing on a clean shopping experience and responsive design.

---

## ✨ Features

- 🖥 Responsive website layout
- 🛍 Product listing page
- 🔍 Product details page
- 🛒 Shopping cart
- 💻 CPU Collection
- 🎮 GPU Collection
- 🧠 RAM Collection
- ⌨ Keyboard Collection
- 🖱 Mouse Collection
- 🎧 Headphones Collection
- 🖥 Motherboard Collection

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
